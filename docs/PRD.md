# 今日热搜 PRD

版本：v1.1
状态：已冻结
冻结日期：2026-06-07
更新日期：2026-06-08

本文档是今日热搜项目的产品目标、MVP 范围、用户体验和验收标准的权威来源。技术栈、接口、数据模型、缓存实现和部署方案以 `docs/TECH_DESIGN.md` 为准。

## 产品概述
一个多平台热点聚合网站。访客打开链接即可浏览微博热搜、知乎热搜词和 B 站热门视频，无需登录。

## 产品目标用户

- 想快速扫一眼多个平台热点的上班族、学生和普通访客。
- 想在一个页面横向比较不同平台热点的人。

## 项目目标

- 作为可公开展示的全栈学习项目。
- 作为 AI Agent 软件工程流程训练项目，沉淀需求、设计、开发、审查和复盘记录。

## 典型使用场景

- 访客打开首页，在短时间内扫完微博、知乎、B 站当前热点。
- 访客发现感兴趣标题后，点击跳转到原平台查看详情。
- 访客点击全页刷新，确认哪些平台更新成功，哪些平台仍展示缓存数据。

## 核心功能

### MVP（必须做）
1. **首页卡片网格**
   - 固定展示 3 张卡片：微博热搜、知乎热搜词、B 站热门。
   - 每张卡片展示平台名、榜单名、Top 10 列表和更新时间。
   - 每条热点展示排名、标题和跳转链接。

2. **数据获取**
   - 前端通过自建后端获取统一格式数据。
   - 前端禁止直接请求微博、知乎、B 站等上游平台 API。
   - 具体接口路径、响应格式和数据模型见 `docs/TECH_DESIGN.md`。

3. **刷新**
   - 页面提供全页刷新入口。
   - 刷新时应展示明确的加载状态。
   - 单个平台刷新失败不得影响其他平台继续展示或更新。

4. **缓存与异常处理**
   - 页面展示每个平台数据的更新时间。
   - 允许后端对各平台数据进行短时间缓存，具体缓存策略见 `docs/TECH_DESIGN.md`。
   - 有旧缓存且刷新失败时，继续展示旧数据，并在更新时间附近以低干扰状态标识提示当前为缓存数据。
   - 无可用缓存且请求失败时，该平台卡片显示失败状态和单平台重试入口。
   - 单个平台失败不得影响其他平台卡片。

5. **部署**
   - 代码托管在 GitHub。
   - 项目可通过公网 HTTPS 访问。

### MVP 非目标

以下功能不属于 MVP，但其中一部分可作为后续迭代方向：

- 登录、用户权限和个性化账号体系。
- 更多平台，例如抖音、百度等。
- 分类 Tab，例如科技、娱乐等。
- 站内搜索、历史榜、暗色模式。
- 个性化推荐、订阅、用户偏好和运营后台。

### 后续可以做

- P1：更多平台、单平台刷新体验优化、数据源健康状态。
- P2：历史快照、站内搜索、分类 Tab、暗色模式。
- P3：趋势对比、热点持续时间统计、公开只读数据看板。

## 页面状态

每个平台卡片至少需要覆盖以下状态：

- `loading`：首次加载或刷新中，展示加载状态。
- `success`：成功获取数据，展示热榜列表和更新时间。
- `stale`：刷新失败但存在旧缓存，继续展示旧榜单，并在更新时间附近显示“缓存数据”或“更新失败”低干扰标识。
- `error`：无可用缓存且请求失败，展示失败提示和单平台重试入口。
- `empty`：请求成功但没有可展示数据，展示空状态提示。

`stale` 状态不得使用全局弹窗，不得遮挡榜单内容，不得将整张卡片替换为错误页；榜单内容仍应可阅读和点击。

## 数据时效语义

- “更新于”表示后端最近一次成功获取该平台数据的时间。
- 页面刷新时间不等于数据更新时间。
- 旧缓存数据需要视觉上可识别，但不应打断用户浏览。
- 如果某个平台数据不可用，不使用长期 mock 数据伪装真实热榜。

## 外链与来源声明

- 点击热点标题应跳转到原平台对应页面。
- 页面不声称拥有上游平台数据版权。
- 页脚展示数据来源、学习项目说明和非商用声明。

## 界面设计要求
- 当前项目采用新闻热榜风格，同时保持专业、清晰、可扫描的信息看板体验。
- 页面重点是多平台热点的横向浏览和快速比较，不做营销落地页。
- 桌面端多列展示，移动端单列展示。
- 卡片分区明确，标题、排名、来源和状态信息易于扫描。
- 页脚包含学习项目说明、数据来源和非商用声明。

## 验收标准

- 打开首页后能看到微博热搜、知乎热搜词、B 站热门三张热点卡片。
- 每张卡片最多展示 Top 10。
- 每条热点标题可点击，并跳转到原平台页面。
- 点击全页刷新后，页面展示明确的刷新加载状态。
- 任一平台刷新失败时，其他平台仍可正常展示或更新。
- 有旧缓存且刷新失败时，对应卡片继续展示旧榜单，并显示缓存数据状态。
- 无可用缓存且请求失败时，对应卡片显示失败提示和单平台重试入口。
- 页面在桌面端多列展示，在移动端单列展示。

## 成功指标

- 正常情况下，首屏能稳定展示 3 个平台的真实热点数据。
- 单个平台异常时，首页仍能展示其他平台数据，并保持可浏览和可刷新。
- 页面可通过公网 HTTPS 访问，并能作为面试项目演示。
- PRD、技术设计、任务记录和审查记录能说明 AI Agent 协作过程。
